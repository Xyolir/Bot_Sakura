Modération

Tickets

Personnalise le message de bienvenue et le règlement. La prévisualisation reflète (à peu près) le rendu Discord.

Le panneau est le message avec le bouton « Ouvrir un ticket ». Le second message est celui que le membre voit dans son ticket. Pense à choisir la catégorie et le rôle staff dans l'onglet Général.

Crée des panneaux de boutons : un clic ajoute ou retire le rôle. Les rôles à permissions sensibles (admin, modération…) sont refusés.

🔒 Il te faut la permission « Gérer les rôles » sur ce serveur pour modifier les panneaux de rôles.

Les membres avec « Gérer les messages » et le rôle staff ne sont jamais sanctionnés.
